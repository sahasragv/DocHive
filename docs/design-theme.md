# DocHive visual theme

The interface uses a light lavender foundation with violet and warm-pink accents, inspired by the user-provided `theme_ex.jpeg` reference. The reference is a visual direction only; DocHive retains its own content, typography, and branding.

## Theme tokens

- Primary violet: `#7653D6`
- Deep violet: `#5834B6`
- Accent pink: `#F05B8D`
- Soft pink: `#FFE4EE`
- Lavender surface: `#F7F4FF`
- Strong lavender surface: `#EDE7FF`

## Image asset

`frontend/public/sidebar-wave.jpg` is the supplied blue/pink wave image. It is used as a decorative, non-interactive background at the bottom of the application sidebar.
